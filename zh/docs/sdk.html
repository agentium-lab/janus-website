SDK 指南

示例适用于 SDK 发布版 1.11.0（Go module / PyPI / npm）。所有片段假定已导出 JANUS_API_KEY，Janus 运行于 http://localhost:8080，租户 acme。

Janus 提供 Go、Python 与 TypeScript 的一等公民 SDK。三者实现相同的核心操作：创建邮箱、发布任务、拉取任务、确认完成。

Go SDK

安装

go get github.com/agentium-lab/Janus/sdk/go

创建客户端

import (
    "os"

    janus "github.com/agentium-lab/Janus/sdk/go"
    "github.com/agentium-lab/Janus/core"
)

client := janus.NewClient(janus.Config{
    BaseURL:  "http://localhost:8080",
    TenantID: "acme",
    APIKey:   os.Getenv("JANUS_API_KEY"),
})

Python SDK

安装

npm install @agentium-lab/janus-sdk

创建客户端

# 创建邮箱（请求模型；也接受普通 dict）
client.create_mailbox(CreateMailboxRequest(id="review-mb", agent_id="reviewer"))

# 发布任务
resp = client.publish_task(PublishTaskRequest(
    id="task-001",
    source_agent="product",
    target_type="capability",
    target_value="code_review",
))

TypeScript SDK

安装

npm install @agentium-lab/janus-sdk

创建客户端

// 创建邮箱
await client.createMailbox("review-mb", { agentId: "reviewer" });

// 发布任务
const resp = await client.publishTask({
    id: "task-001",
    sourceAgent: "product",
    targetType: "mailbox",
    targetValue: "review-mb",
});

CLI

Janus CLI 提供终端下的任务与邮箱管理：

# 任务操作
janus task list --tenant acme
janus task get task-001 --tenant acme
janus task replay task-001 --tenant acme

# 邮箱操作
janus mailbox list --tenant acme
janus mailbox inspect review-mb --tenant acme

# 系统
janus status
janus version
三个 SDK 都支持 HTTP 与 gRPC 传输，并遵循相同的错误信封格式。运维操作请使用 CLI —— 从 DLQ 重放、检查邮箱深度、查看系统健康状态。
