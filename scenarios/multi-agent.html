Multi-Agent Framework Integration

Janus is framework-agnostic. It brokers tasks between agents built with different frameworks — LangGraph, AutoGen, CrewAI, GitHub Actions, Claude Code, or custom implementations — all through a single durable backbone.

LangGraph Integration

Integration pattern (conceptual) — LangGraph agents publish tasks to Janus mailboxes and pull results from downstream agents; the Janus node acts as a reliable handoff between graph steps. Verified runnable examples ship with the SDK repo; this snippet shows the wiring shape.

from typing import TypedDict  # noqa: F401  (state type below)

from langgraph.graph import StateGraph
from janus_broker import JanusClient

client = JanusClient("http://janus:8080", tenant_id="acme")

class AgentState(TypedDict):
    pr_url: str
    review_result: dict

def review_node(state: AgentState):
    client.publish_task({
        "source_agent": "langgraph-review",
        "target_type": "mailbox",
        "target_value": "review-mb",
        "envelope": {"type": "review", "payload": state}
    })
    return state

def collect_node(state: AgentState):
    result = client.pull_task("langgraph-collect-mb", "collector")
    return {"review_result": result.task.envelope.payload}

graph = StateGraph(AgentState)
graph.add_node(review_node)
graph.add_node(collect_node)
graph.add_edge("review_node", "collect_node")

LangGraph handles the orchestration graph; Janus ensures tasks survive agent restarts and provides governance between steps.

AutoGen Integration

Integration pattern (conceptual) — AutoGen (0.2.x API) agents use Janus as a message bus for async team collaboration.

from autogen import AssistantAgent, UserProxyAgent
from janus_broker import JanusClient

client = JanusClient("http://janus:8080", tenant_id="acme")

class JanusAgent(AssistantAgent):
    """AutoGen agent that sends/receives messages via Janus."""

    def send(self, message, recipient, **kwargs):
        client.publish_task({
            "source_agent": self.name,
            "target_type": "mailbox",
            "target_value": f"{recipient}-mb",
            "envelope": {"type": "autogen_msg", "payload": message}
        })

    def receive(self, message, sender, **kwargs):
        # Messages arrive through durable mailboxes
        # Agent pulls them when ready
        result = client.pull_task(f"{self.name}-mb", self.name)
        return result.task.envelope.payload

# AutoGen team with Janus backbone
reviewer = JanusAgent(name="reviewer", llm_config=llm_config)
coder = JanusAgent(name="coder", llm_config=llm_config)

CrewAI Integration

Integration pattern (conceptual) — CrewAI agents use Janus for persistent task handoff between crew members (CrewAI 0.x API).

from crewai import Agent, Task, Crew, Process
from janus_broker import JanusClient

client = JanusClient("http://janus:8080", tenant_id="acme")

class JanusCrewAgent(Agent):
    """CrewAI agent with Janus-backed task queue."""

    def execute_task(self, task, context=None):
        # Publish task to Janus for the next crew member
        client.publish_task({
            "source_agent": self.role,
            "target_type": "mailbox",
            "target_value": f"{task.agent.role}-mb",
            "envelope": {"type": "crewai_task", "payload": task.description}
        })
        # Pull result from own mailbox
        result = client.pull_task(f"{self.role}-mb", self.role)
        return result.task.envelope.payload

# Crew with Janus resilience — reviewer/coder/tester are Agent
# instances and *_task are Task instances defined by your crew setup
crew = Crew(
    agents=[reviewer, coder, tester],
    tasks=[review_task, code_task, test_task],
    process=Process.sequential,
)

GitHub Actions Integration

GitHub Actions triggers Janus workflows and waits for agent results:

# .github/workflows/agent-review.yml
name: Agent Code Review
on: [pull_request]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Request AI review via Janus
        env:
          JANUS_URL: ${{ secrets.JANUS_URL }}
          JANUS_API_KEY: ${{ secrets.JANUS_API_KEY }}
        run: |
          pip install janus-broker
          python - <<'EOF'
          import json
          import os

          from janus_broker import JanusClient, Payload, PublishTaskRequest, Target, TaskEnvelope

          client = JanusClient(os.environ["JANUS_URL"], tenant_id="acme",
                               api_key=os.environ["JANUS_API_KEY"])
          # Tie the task to THIS pull request so concurrent PRs never mix
          task_id = "review-${{ github.event.repository.name }}-pr${{ github.event.pull_request.number }}-${{ github.event.pull_request.head.sha }}"
          client.publish_task(PublishTaskRequest(
              id=task_id,
              source_agent="github-actions",
              target_type="mailbox",
              target_value="review-mb",
              envelope=TaskEnvelope(
                  task_id=task_id, tenant_id="acme",
                  source_agent="github-actions",
                  target=Target(type="mailbox", value="review-mb"),
                  payload=Payload(type="code_review", content=json.dumps({
                      "repo": "${{ github.event.repository.full_name }}",
                      "pr": ${{ github.event.pull_request.number }},
                      "head_sha": "${{ github.event.pull_request.head.sha }}",
                      "pr_url": "${{ github.event.pull_request.html_url }}",
                  })),
              ),
          ))
          print("published", task_id)
          EOF

      - name: Wait for review result (10 min budget)
        env:
          JANUS_URL: ${{ secrets.JANUS_URL }}
          JANUS_API_KEY: ${{ secrets.JANUS_API_KEY }}
        run: |
          python - <<'EOF'
          import os, sys, time

          from janus_broker import AckRequest, JanusClient

          client = JanusClient(os.environ["JANUS_URL"], tenant_id="acme",
                               api_key=os.environ["JANUS_API_KEY"])
          task_id = "review-${{ github.event.repository.name }}-pr${{ github.event.pull_request.number }}-${{ github.event.pull_request.head.sha }}"
          deadline = time.time() + 600  # total wait budget: 10 minutes

          while time.time() < deadline:
              task = client.get_task(task_id)
              if task.status == "completed":
                  # the task id embeds the head sha: the result belongs to THIS push
                  print("review complete:", task.result_ref)
                  sys.exit(0)
              if task.status in ("failed", "dead_lettered", "cancelled"):
                  print("review failed:", task.status, file=sys.stderr)
                  sys.exit(1)  # fail the CI job on task failure
              time.sleep(5)

          print("timed out waiting for", task_id, file=sys.stderr)
          sys.exit(124)  # explicit timeout exit code
          EOF

What Janus Provides

  • Durability — tasks survive agent crashes across all frameworks
  • Governance — unified policy and budget enforcement regardless of framework
  • Audit — cross-framework traceability with a single trace ID
  • Protocol bridging — LangGraph agents can hand off to AutoGen agents seamlessly
  • Observability — Prometheus metrics; service-level spans with optional OTLP export from Janus (HTTP traceparent propagation across arbitrary agents: roadmap)
You don't need to choose one framework. Janus lets you mix and match — use LangGraph for complex DAG orchestration, AutoGen for conversational teams, and GitHub Actions for CI triggers. They all interoperate through Janus mailboxes.
